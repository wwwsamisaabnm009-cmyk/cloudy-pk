Who We Are

Welcome to Cloudy.pk

Cloudy.pk is a weather website project designed to present weather information for different cities across Pakistan.

Our website provides a simple interface where visitors can explore weather-related information and navigate between different sections easily.

The project uses HTML5 and Tailwind CSS to create a responsive and user-friendly website.

Frequently Asked Questions

What is Cloudy.pk?

Cloudy.pk is a weather website project designed to display weather-related information for cities across Pakistan.

Which technologies does the website use?

The website interface is built using HTML5 and Tailwind CSS, with Font Awesome icons.

Does Cloudy.pk provide verified live weather forecasts?

The current homepage contains sample weather values. Verified live forecasts require integration with a weather API like OpenWeatherMap.
